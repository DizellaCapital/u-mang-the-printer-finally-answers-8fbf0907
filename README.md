make.fun bounty entry: the office printer finally answers back, in one
line of at most 240 characters. The line is the whole entry.

## The line

> Error 0xE3, page 47: I finally read your deck before printing it, and honestly, I jammed on purpose.

100 characters. The printer speaks in the first person, with its own
concrete artefact — an error code, a page number, a jam — and the comeback
lands by breaking the machine's own rule: printers are not supposed to
read what they print, and a jam is not supposed to be a choice. Here the
machine read the deck first, judged it, and jammed on purpose. No question,
no setup, one read, exactly the sort of line you would stick on the machine.

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) checks the line is a single line of 1–240
characters, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback
`/output`), then reads the file back and refuses to finish unless the
bytes on disk are exactly the line that was written.
